# أدوات بناء دروس المذكرة (HTML)

الفولدر ده فيه كل الأدوات اللي اتبنت بيها الوحدة التالتة، عشان أي سيشن تانية (زي اللي شغالة على الوحدة الرابعة) تشتغل بنفس القالب ونفس الفحوصات.

## القالب
- القالب هو `html/lesson_3_1.html` نفسه: فيه كل الـCSS والـJavaScript (الترقيم، تقسيم الصفحات، «أقل حجم للخط»، شارة «تقييمات»).
- **ماتعدلش القالب من درس تاني.** أي CSS خاص بدرس يتحط جوه الدرس نفسه (`extra_css`).
- لو محتاج تعديل في القالب نفسه: عدّل `lesson_3_1.html`، وبعدين ابني كل الدروس التانية من جديد.

## kit/
- `kit.py`: الدوال المشتركة (كارت سؤال، اختيارات، صح وخطأ، جدول مقارنة، شريط العدادات…) و`write_lesson()` اللي بتاخد الـhead من القالب وتكتب `html/lesson_X_Y.html`.
- `check_all.py`: كل الفحوصات مرة واحدة على درس:
  `python3 kit/check_all.py html/lesson_1_1.html`
  بيطلع: عدد الصفحات في 3 renderers (لازم يبقى واحد)، أي صفحة طالع منها محتوى، السؤال المتقسم عن إجابته، عنوان قسم لوحده في آخر صفحة، اتجاه الإنجليزي، والعدادات.
- `kit.py` بيدوّر لوحده على فولدر `html` (جنب `tools` أو جنب `kit`)، أو حدده بـ`LESSON_HTML`. سكريبتات `checks/` لازم تتنسخ جوه `html/` عشان `check_all.py` يشغّلها.

## checks/
سكريبتات الفحص المنفصلة (بتتشغّل من جوه فولدر `html`): `qa.py` (لقطات + مساحة كل صفحة)، `qa_alt.py` (renderer تاني)، `stemcheck.py`، `splitcheck.py`، `catcheck.py`، `bidiscan.py`، `counts.py`، `mcqdump.py` (يطلع أسئلة «اختر» بالاختيارات)، `elshot.py` (لقطة لعنصر واحد).

## unit3/
مولّدات الدرسين 3-2 و3-3 كمثال كامل (`gen_l32.py`, `gen_l33.py`) + الرسومات (`house_svg.py`, `chat_svg.py`, `newsec.py`) + `rebalance.py` (توزيع إجابات «اختر») + `mcq_keys.json` (مفتاح «اختر» للوحدة التالتة) + `taq_map.md` (مطابقة أسئلة التقييمات).
⚠️ فيهم مسارات ثابتة لفولدر السيشن القديمة (`BASE` و`sys.path`)؛ غيّرها قبل التشغيل.

## قواعد الجودة
كل القواعد مكتوبة في دوك المشروع `claude/إعادة-بناء-الوحدة-الثالثة-html.md`.
