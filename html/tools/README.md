# أدوات بناء دروس المذكرة (HTML)

الفولدر ده جنب ملفات الدروس في `html/`. كل الأوامر بتتشغل من جوه فولدر `html`.

| الملف | وظيفته |
|---|---|
| `../lesson_3_1.html` | **القالب**: الستايل والسكريبتات (التقسيم على الصفحات، الترقيم، أقل حجم خط، شارة «تقييمات»). أي درس جديد بياخد الـhead بتاعه. تعديل مشترك = يتعمل هنا وبعدين يتعاد توليد كل الدروس. |
| `gen_l32.py` · `gen_l33.py` | مولّدات الدرسين 3-2 و3-3: نموذج لأي درس جديد (`gen_lXY.py`). `python3 tools/gen_l33.py` بيكتب `lesson_3_3.html`. |
| `newsec.py` · `house_svg.py` · `chat_svg.py` | أيقونات ورسومات SVG بتستخدمها المولّدات. |
| `check.py` | **كل الفحوصات في أمر واحد**: `python3 tools/check.py lesson_3_1.html lesson_3_2.html --shots`. لازم يطلع `ALL OK`. |
| `rebalance.py` · `mcq_keys.json` | توزيع إجابات «اختر» على أ/ب/ج/د + المفتاح المحفوظ. |
| `PLAYBOOK.md` | قواعد بناء أي درس بنفس جودة الوحدة التالتة. **اقراه قبل أي درس.** |

المتطلبات: `pip install playwright && playwright install chromium`.
